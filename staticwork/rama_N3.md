# РГР, статика: расчёт рамы, вариант N = 3

## 0. Как читается схема

- Ось **x** вправо, ось **y** вверх, начало координат в точке **A** (левая нижняя опора). Моменты считаются **положительными против часовой стрелки**.
- Обозначения точек (на схеме букв нет, они введены для расчёта):
  - **A**: левая опора, скользящая (на катках), реакция только вертикальная.
  - **E**: шарнир на нижней балке, где стоят две пары моментов M.
  - **H**: шарнир наверху справа.
  - **D**: правая скользящая опора.
  - **B**: заделка внизу средней стойки (если у вас она называется C, замените B на C везде).
- Координаты точек (м):

| Точка | x | y |
|---|---|---|
| A | 0 | 0 |
| E | 6 | 6 |
| H | 18 | 9 |
| D | 22 | 9 |
| B | 18 | 0 |

- Сила F₂ приложена на расстоянии 0,6·l₂ = 2,4 м от D, то есть в точке x = 19,6.
- Сила F₂ направлена вниз-влево, к балке. Угол α отсчитан от балки вправо.
- Нагрузка q давит вправо на левую стенку рамы: на левую стойку (высота h₁) и на «ступеньку» (высота h₂).
- Пара моментов в шарнире E: на левое тело действует M против часовой стрелки, на правое такой же M по часовой.

## 1. Исходные данные

F₁ = 100 кН, F₂ = 120 кН, α = 60°, q = 25 кН/м, M = 120 кН·м, l₁ = 6 м, l₂ = 4 м, h₁ = 6 м, h₂ = 3 м.

## 2. Статическая определимость

Рама состоит из 3 тел: **AE**, **EBH** (с заделкой) и **HD**. Для каждого тела можно написать 3 уравнения, всего 3·3 = 9.

Неизвестные реакции:

- опора A (скользящая): 1;
- шарнир E: 2;
- шарнир H: 2;
- заделка B: 3 (две силы и момент);
- опора D (скользящая): 1.

Итого 1 + 2 + 2 + 3 + 1 = 9. Уравнений 9, неизвестных 9, значит рама статически определима.

## 3. Заменяем распределённую нагрузку силами

Равномерная нагрузка заменяется одной силой Q = q·(длина), приложенной в середине участка и направленной туда же, куда нагрузка (вправо).

- На левую стойку (тело AE): **Q₁ = q·h₁ = 25·6 = 150 кН**. Приложена на высоте 3 м (в середине стойки), направлена вправо.
- На ступеньку (тело EBH): **Q₂ = q·h₂ = 25·3 = 75 кН**. Приложена на высоте 6 + 1,5 = 7,5 м, направлена вправо.

Разложение F₂ на составляющие:

- F₂ₓ = F₂·cos 60° = 120·0,5 = **60 кН** (влево);
- F₂ᵧ = F₂·sin 60° = 120·0,866 = **103,92 кН** (вниз).

## 4. Правило для реакций в шарнире

Через шарнир тела давят друг на друга с равными и противоположными силами (третий закон Ньютона). Поэтому в шарнире E на левом теле рисуются стрелки X_E и Y_E, а на правом теле такие же по величине, но направленные в обратную сторону. То же в шарнире H.

## 5. Решение

Начинаем с тела, где меньше всего неизвестных, и идём по цепочке.

### Тело HD (самое правое)

Неизвестные: X_H, Y_H, R_D. Стрелки на схеме:

- X_H (от тела EBH на HD): вправо;
- Y_H: вверх;
- R_D: вверх (опора на катках);
- F₂: вниз-влево, раскладывается на 60 кН влево и 103,92 кН вниз.

**1) ΣFₓ = 0:** X_H − F₂·cosα = 0, откуда **X_H = 60 кН** (вправо).

**2) ΣM_H = 0.** Сила R_D стоит справа от H и тянет вверх, поэтому крутит против часовой (+). Сила F₂ᵧ стоит на расстоянии 0,4·l₂ = 1,6 м справа от H и тянет вниз, поэтому крутит по часовой (−). Горизонтальная составляющая F₂ₓ лежит на оси балки, плеча у неё нет, момента нет.

R_D·l₂ − F₂·sinα·0,4·l₂ = 0
R_D·4 − 103,92·1,6 = 0, откуда **R_D = 41,57 кН** (вверх).

**3) ΣM_D = 0.** Сила Y_H слева от D тянет вверх, крутит по часовой (−). Сила F₂ᵧ на расстоянии 2,4 м слева от D тянет вниз, крутит против часовой (+).

−Y_H·l₂ + F₂·sinα·0,6·l₂ = 0
−Y_H·4 + 103,92·2,4 = 0, откуда **Y_H = 62,35 кН** (вверх).

Проверка по ΣFᵧ: 62,35 + 41,57 − 103,92 = 0 ✓.

### Тело AE (левое)

Силы на этом теле:

- R_A: вверх, в точке A;
- Q₁ = 150 кН: вправо, на высоте 3 м;
- X_E и Y_E в шарнире E: направление пока принимаем X_E вправо, Y_E вверх;
- момент M = 120 кН·м против часовой.

**1) ΣM_E = 0.** Пока неизвестен только R_A.

- R_A стоит на 6 м левее E и тянет вверх, крутит по часовой: −R_A·6.
- Q₁ действует на 3 м ниже E и тянет вправо. Нижняя точка идёт вправо, это против часовой: +150·3 = +450.
- Пара M: +120.

−6·R_A + 450 + 120 = 0, откуда **R_A = 95 кН** (вверх).

**2) ΣFₓ = 0:** X_E + Q₁ = 0, откуда **X_E = −150 кН**. Знак «−» означает, что на теле AE эта сила направлена **влево**.

**3) ΣFᵧ = 0:** R_A + Y_E = 0, откуда **Y_E = −95 кН**. На теле AE она направлена **вниз**.

### Тело EBH (среднее, с заделкой)

На этом теле действуют:

- в шарнире E: силы, **обратные** найденным, то есть **150 кН вправо** и **95 кН вверх**;
- в шарнире E: момент M = 120 кН·м по часовой (−120);
- Q₂ = 75 кН: вправо, на высоте 7,5 м;
- F₁ = 100 кН: вправо, на высоте 4,8 м (0,8·h₁ = 4,8 м);
- в шарнире H: силы, обратные X_H и Y_H, то есть **60 кН влево** и **62,35 кН вниз**;
- заделка B: X_B, Y_B и момент M_B (направления пока выбираем: X_B вправо, Y_B вверх, M_B против часовой).

**1) ΣFₓ = 0:** 150 + 75 + 100 − 60 + X_B = 0, откуда **X_B = −265 кН**. Реакция направлена **влево**.

**2) ΣFᵧ = 0:** 95 − 62,35 + Y_B = 0, откуда **Y_B = −32,65 кН**. Реакция направлена **вниз**.

**3) ΣM_B = 0** (моменты относительно заделки B, точка (18; 0)):

| Сила | Объяснение | Момент, кН·м |
|---|---|---|
| 150 кН вправо в E | точка на 6 м выше B, сила вправо крутит по часовой | −150·6 = −900 |
| 95 кН вверх в E | точка на 12 м левее B, сила вверх крутит по часовой | −95·12 = −1140 |
| пара M | по часовой | −120 |
| Q₂ = 75 кН | на 7,5 м выше B, вправо | −75·7,5 = −562,5 |
| F₁ = 100 кН | на 4,8 м выше B, вправо | −100·4,8 = −480 |
| 60 кН влево в H | точка на 9 м выше B, сила влево крутит против часовой | +60·9 = +540 |
| 62,35 кН вниз в H | точка прямо над B, плеча нет | 0 |
| M_B | неизвестен | +M_B |

−900 − 1140 − 120 − 562,5 − 480 + 540 + M_B = 0, откуда **M_B = 2662,5 кН·м** (против часовой).

## 6. Результаты

| Реакция | Значение | Куда направлена |
|---|---|---|
| R_A | 95 кН | вверх |
| X_E (на теле AE) | −150 кН | влево (на теле EBH вправо) |
| Y_E (на теле AE) | −95 кН | вниз (на теле EBH вверх) |
| X_H (на теле HD) | 60 кН | вправо (на теле EBH влево) |
| Y_H (на теле HD) | 62,4 кН | вверх (на теле EBH вниз) |
| R_D | 41,6 кН | вверх |
| X_B | −265 кН | влево |
| Y_B | −32,6 кН | вниз |
| M_B | 2660 кН·м | против часовой |

## 7. Проверка: уравнения равновесия всей рамы

Для всей рамы внутренние шарниры и пары M в сумме не дают вклада. Нагрузки заменяем силами Q₁, Q₂, F₁, F₂.

**ΣFₓ:** 150 + 75 + 100 − 60 − 265 = **0** ✓

**ΣFᵧ:** 95 − 32,65 + 41,57 − 103,92 = **0** ✓

**ΣM_A** (относительно точки A):

| Слагаемое | Значение, кН·м |
|---|---|
| Q₁ | −150·3 = −450 |
| Q₂ | −75·7,5 = −562,5 |
| F₁ | −100·4,8 = −480 |
| F₂ (обе составляющие) | −103,92·19,6 + 60·9 = −1496,9 |
| R_D | +41,57·22 = +914,5 |
| Y_B | −32,65·18 = −587,6 |
| M_B | +2662,5 |

Сумма: −3577,0 + 3577,0 = **0** ✓ (положительные 3577,0, отрицательные 3577,0).

Все три уравнения выполняются, расчёт верный.
